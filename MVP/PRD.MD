# 임대톡(Talk) MVP PRD (Product Requirements Document)

## 1.1 프로젝트 개요
- **서비스명:** 임대톡(Talk) (가칭)
- **프로젝트 목표 (Vision):** "어려운 공공임대 정책을 내 돈(자산)의 관점에서 쉽게 풀어주는 동반자"
- **MVP 타겟 고객:** 공공임대/분양 청약에 관심 있는 무주택 1인 가구 (2030 중심)
- **서비스 형태:** 반응형 웹 (Mobile-First)
- **톤앤매너:** 친근하고 똑똑한 조력자 (Friendly & Smart Assistant)

## 1.2 핵심 가치 (USP - Unique Selling Proposition)
- **기존 서비스의 문제점:** "내가 지원할 수 있는지", "공고문이 무슨 뜻인지" 알기 어려움. 정보 중심.
- **임대톡의 해결책:** "여기에 당첨되면 10년 뒤 얼마를 버는지(자산 관점)"를 최우선으로 보여주고, 복잡한 공고를 AI가 3줄 요약하여 친구처럼 알려줌.

## 1.3 핵심 기능 요구사항 (Functional Requirements)

| 기능 분류 | 상세 요구사항 | 우선순위 |
| :--- | :--- | :---: |
| **인증/회원** | • 카카오/네이버 소셜 간편 로그인 (Supabase Auth 연동)<br>• 최초 로그인 시 '1인 가구 조건(나이, 무주택기간, 청약통장 횟수, 거주지역)' 입력 (이후 수정 가능) | P1 |
| **메인 피드** | • 세로 스크롤 기반의 카드 리스트 뷰 (오늘의집/토스 스타일)<br>• 카드 노출 정보: 단지명, AI 3줄 요약, 보증금/월세, [예상 시세 차익(핵심)]<br>• 우측 하단 플로팅 버튼(FAB) 클릭 시 '지도 뷰' 전환 | P1 |
| **상세 페이지** | • [시뮬레이터] 최상단에 "OO님, 10년 뒤 예상 시세 차익은 1.5억 원이에요 🚀" 직관적 노출<br>• [AI 요약] 마크다운 형태의 깔끔한 공고문 요약 (자격 컷, 일정 등)<br>• [액션] 원문 PDF 다운로드 버튼 및 LH/SH 청약센터 링크 아웃 | P1 |
| **개인화 필터** | • 내 조건(가점/지역)에 맞는 공고만 메인 피드에 노출<br>• 조건 미달 공고는 "OO님은 소득 기준 초과로 지원이 어려워요 🥲" 안내 | P2 |
| **알림 (구독)** | • 이메일 기반 정밀 타격 알림 (내 조건에 맞는 공고 오픈 시 발송)<br>• 주 1회 "이번 주 1인 가구 줍줍 리스트" 뉴스레터 발송 | P2 |
